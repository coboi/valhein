# Changelog

## [0.1.0] — 2026-08-01

Initial public release of the Valhein React component library.

- 40 components with TypeScript types, CSS Modules styling, and dark-mode +
  accent theming via `data-theme` / `data-accent` tokens.
- Peer dependencies: `react` 19, `@base-ui/react` ^1.6, `@phosphor-icons/react` ^2.1.
- Published as ESM with a single stylesheet export (`valhein/style.css`).
